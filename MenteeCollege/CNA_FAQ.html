Nurse Aide (CNA) Certification Program FAQ - Georgia

Program Length and Schedule

Duration: 6 Weeks

  • Three days a week (one day is open lab)
  • 9 AM to 3 PM

Application and Fees

  • Application Fee: $35.00 (non-refundable)
  • Tuition: $1,743.00
  • Payment Plan Available

Program Requirements

  • TB skin test (The TB skin test must have been completed within the past 12 months)
  • Two forms of ID (Photo ID + SS Card)
  • Covid-19 Vaccine (required for clinicals)
  • Mandatory Background Check

State License Exam Information

  • Exam Fee: $35 (Written)
  • Virtual Skills Exam (No Cost)
  • Registration is done online with provided instructions
  • The exam consists of two parts:
    • Written
    • Skills
  • You can attempt the exam up to three times. If not passed by the third attempt, retaking the CNA class is mandated by the state.
  • If only one part of the exam is failed, only the failed part needs to be retaken.
  • Retake fees:
    • Written - $35.00

State Exam Location

The written exam is online. The skills exam is taken at Mentee College.
