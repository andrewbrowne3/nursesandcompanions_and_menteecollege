BosDates Lite Readme and Installation Guide
Last modified 06/07/2007

BosDates Lite is a flexible calendar system which allows
you to publish events worldwide to your target audience.

These scripts are not shareware, freeware, nor part of the

You are allowed to install the BosDates Lite Calendar System
to one domain name.  Multiple domain installations are
available, please contact sales@bosdev.com for more
information.


REQUIREMENTS:
BosDates Lite requires a webserver capable of running PHP v4.1+
and MySQL v3.23+


INSTALLATION:
Unzip and upload the scripts into a directory on your server.
Once uploaded, there should be 2 subdirectories named Admin
and Skins.

After uploading, chmod the /connect.php file to 0777 and run
<directory>/install.php  You will need to have a database
created before you run this script, as well as a username
and password for that database.

Once the installation is complete, delete or rename the
install.php file from the server and CHMOD /connect.php back
to 0755.

You will then be able to login to the administration areas to
configure your calendar.
